# Penguin Hub

## Overview
This Roblox script provides powerful automation features for multiple games.

---

## 📦 Current Features — Ohio
- **🛠️ AutoFarm:** Automatically farms resources and in‑game currency.  
- **📍 Teleport:** Instantly teleport to key locations.  
- **🛡️ Damage Escape:** Automatically teleports you away when taking damage.  

---

## 📦 Current Features — Virus Border Roleplay
- **🛠️ AutoFarm:** Automatically farms candy for the ongoing Halloween event.  
- **📍 Webhook:** Logs your obtained rewards using your Discord webhook.  

---

- ✅ Currently supports all kinds of devices.
